# MisarPost agents

Task-scoped agents built on the @misarpost/mcp MCP server. Each bundles a subset
of the tools with the rules for using them safely.

| Agent | Purpose |
| --- | --- |
| `content-planner` | Plans a content calendar from trends, past performance and what is already scheduled. |
| `repurposer` | Turns one piece of content into channel-native variants and previews each before scheduling. |
| `performance-analyst` | Reports what performed and recommends the next highest-impact change. |

All of them require authentication — see https://docs.misar.io/post/mcp. Generated by
`scripts/mcp/generate-distribution.mjs`; edit the product entry, not these files.
